# 风声 Fengsheng

macOS 语音输入应用的官方安装包发布仓库。

[下载最新版](https://github.com/PeiFeng877/Fengsheng-releases/releases/latest)

支持 macOS 14 及以上，Apple silicon 与 Intel。安装包使用 Developer ID 签名；具体版本的 Apple 公证状态与 SHA256 校验值请查看发行说明。

录音方式支持点按切换与按住说话；ASR 可切换 Qwen3-ASR 与 Qwen-Audio-3.1 实时识别。

此仓库提供安装包及发行说明。语音服务需要风声账号；账号开通独立于安装包下载。
